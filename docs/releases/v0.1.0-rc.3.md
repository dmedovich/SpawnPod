# SpawnPod v0.1.0-rc.3

Linux/amd64 release candidate for Forgejo Runner v13.1.0.

- Report output-write failures from `doctor` and `smoke`. Smoke cleanup remains
  registered even when writing the first status message fails.
- Resolve Go lint findings in resource cleanup, error handling and tests.
- Move K3s acceptance tests, workflow fixtures and local setup helpers from
  `deploy/` to `tests/integration/`. Installation manifest paths are unchanged.
- Simplify documentation, correct installation and publication commands,
  and describe the current security model separately from release history.

The [rc.2 fixes](v0.1.0-rc.2.md) are included. The supported platform and
execution restrictions remain documented in [SPEC.md](../SPEC.md) and
[SECURITY.md](../SECURITY.md).

Validation: `make check` (full tests, vet and module verification), the short
race suite, Go lint checks, actionlint and script syntax checks passed. Live K3s results in
[VALIDATION.md](../VALIDATION.md) were recorded for rc.2; the live cluster suite
was not repeated for this release.
