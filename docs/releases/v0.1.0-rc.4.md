# SpawnPod v0.1.0-rc.4

Release packaging and distribution update for Forgejo Runner v13.1.0.

- Publish Linux/amd64 and Linux/arm64 binary archives with SHA-256 checksums.
- Publish a multi-platform runtime image at `ghcr.io/dmedovich/spawnpod:v0.1.0-rc.4`,
  with SBOM and provenance attestations and a keyless Cosign signature.
- Attach SPDX SBOMs and GitHub build attestations to the binary archives.
- Find the Go LICENSE in Fedora's system license directory when it is absent
  from `GOROOT`.
- Verify tests, vet, archives, binary versions and architecture before the
  release workflow publishes artifacts.

Linux/amd64 remains the validated deployment platform. ARM64 packages and
images build successfully, but execution on ARM64 hardware has not been tested.
The earlier local K3s results in [VALIDATION.md](../VALIDATION.md) were recorded
for rc.2 and have not been repeated for rc.4.
