# SpawnPod v0.1.0-rc.2

Linux/amd64 release candidate for Forgejo Runner v13.1.0.

- Prevent step descendants from escaping cleanup through new sessions/process groups.
  This restricts daemonization, job control and namespace creation; see [security](../SECURITY.md).
- Bound stalled output, cancellation, shutdown and failure-state persistence.
  Release the command slot before delivering completion, and reserve the process-group
  leader PID until cleanup finishes.
- Replace infrastructure diagnostics with fixed messages at the reviewed boundaries.
  Workflow stdout/stderr remains raw and must be treated as potentially sensitive.
- Recover supported records even when incompatible records exist; preserve rejected
  data and prevent new environments after detected incompatibility.
- Update the release toolchain to Go 1.27.2 and dependencies to resolve findings
  reported by govulncheck. The module now requires Go 1.26 or later.
- Add opt-in local K3s admission, network, recovery, capacity and quiescent
  controller upgrade/rollback acceptance tests.
- Build packages from fresh staging directories and reject stale/dirty production
  image inputs.

See [validation](../VALIDATION.md) for results and limitations. Real ARM64,
target-server capacity, hostile tenant isolation and live-job version migration
are outside this candidate's support claim. Existing rc.1 artifacts do not
contain these fixes. Drain/remove jobs before upgrading or rolling back.
